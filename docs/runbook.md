# Operational Runbook

## Budget Monitoring Procedure

1. Navigate to Azure Cost Management.
2. Review current spend against monthly budget.
3. Verify alert thresholds at 50%, 80%, and 100%.
4. Investigate cost spikes using Cost Analysis filters.
5. Identify resource group responsible for anomaly.

## Incident Response Steps

- Validate unexpected resource provisioning.
- Check activity logs for deployment origin.
- Remove unused compute resources.
- Confirm deallocation of managed disks.
- Document resolution in incident report.

## Monthly Review Checklist

- Audit idle resources.
- Validate tagging compliance.
- Review budget thresholds.
- Update cost forecast projections.
